# Proyecto Final UTN FRC: Redler AGD Río Primero

Legajo de planos Rev. E: armado del DWG según normas IRAM.

- `docs/fase0/`: Fase 0. Datos maestros verificados contra la Rev E, discrepancias, faltantes y preguntas.
- `fuentes/codigo_RevE/`: código Python que generó el PDF Rev E. Es la fuente de coordenadas (X, s, Z) y trae las fotos del relevamiento.

## Herramientas

- `herramientas/panel-mantenimiento/`: panel de mantenimiento para Windows al estilo FNAF 3. Cierra procesos en segundo plano, manda duplicados a la Papelera, libera RAM y hace una optimización general. Ver su [README](herramientas/panel-mantenimiento/README.md).
